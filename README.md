# ProxiSpeak

**Geospatial Proximity Audio Ecosystem**

ProxiSpeak is a real-time virtual environment where users can move avatars around a shared world and communicate through proximity-based audio.

## Project Goals

* Real-time avatar movement
* Shared virtual world
* Distance-based voice communication
* WebRTC audio communication

## Technology Stack

* React
* Node.js and Express
* Socket.IO
* MongoDB
* WebRTC
* Web Audio API

## Team Workflow

Each team member will work on their own GitHub branch.
